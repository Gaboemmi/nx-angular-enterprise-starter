# Nx Angular Enterprise Starter

A reference implementation for building modern Angular enterprise
applications with Nx and AI-assisted engineering practices.

## Vision

This project aims to demonstrate how a maintainable, scalable and
AI-ready Angular application can be structured.

## Current Status

Early foundation stage.

The repository currently contains the initial Angular and Nx workspace.
Architecture, conventions and enterprise capabilities will be introduced
incrementally through documented decisions.

## Core Areas

- Modern Angular
- Nx monorepo architecture
- Enterprise engineering practices
- AI-assisted development
- Documentation-driven decisions
- Long-term maintainability

## Principles

- Architecture before accidental complexity
- Decisions must be documented
- AI accelerates engineering but does not replace engineering judgment
- Prefer stable and supported technologies
- Build incrementally and validate continuously

## Roadmap

### Phase 0 — Foundation Research

Research and validate the most important principles related to:

- Angular
- Nx
- Software architecture
- AI-assisted development

Research will happen alongside implementation rather than blocking it.
