# Decisions

This directory is reserved for short, agent-oriented summaries of decisions that
materially affect future implementation and cannot be inferred reliably from
code. It is not a conversation history.

The authoritative architectural ADRs live in
[docs/decisions/](../../docs/decisions/README.md). Do not duplicate their full
content here or create a competing ADR system.

Add a summary here only when it points agents to an accepted decision they need
across sessions. This directory may be removed later if the ADRs alone remain
sufficient.
